# Processo de desenvolvimento (registro)

Esta pasta guarda os arquivos que usei para conduzir o desenvolvimento com o Claude Code (ver
["Uso de IA" no README](../../README.md#uso-de-ia)). Eles não são necessários para rodar ou avaliar o projeto;
ficam aqui como registro de como o trabalho foi planejado, executado e validado.

| Arquivo | O que é |
|---|---|
| [`PLAN-ORIGINAL.md`](PLAN-ORIGINAL.md) | Primeiro plano: leitura do enunciado, stack e estrutura |
| [`PLAN.md`](PLAN.md) | Plano aprovado, com as decisões técnicas |
| [`steps/`](steps/README.md) | O plano dividido em 18 passos, um arquivo por passo |
| [`CLAUDE.md`](CLAUDE.md) | Instruções e status para o agente, atualizados a cada passo |
| [`VALIDACAO.md`](VALIDACAO.md) | Checklist que eu usei para validar cada passo antes de seguir |

Os caminhos citados dentro desses arquivos são os da época (ex.: `docs/steps/`, `CLAUDE.md` na raiz); os
arquivos foram movidos para cá depois da entrega.
